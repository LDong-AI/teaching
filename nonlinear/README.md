## 第06次课补充

| 文件 | 用途 |
|------|------|
| `第06次课_补充_μ与Rn计算方法.html` | **完整专节**：\(\mu_n\)、\(R_n\) 原理/步骤/算例 + 互动验算 |

### 部署到 course.hdeda.cn

1. 将本目录同步到服务器 `nonlinear/` 下同名路径；
2. 若线上已有完整主课件：把 `section-mu-rn.inc.html` 中的 `<section id="mu-rn-calc">` 粘贴到费根鲍姆章节附近，并保留指向完整专节的链接；
3. 确认 `nl-common.css` 与 MathJax 可被页面加载。

### 本地预览

在仓库根目录启动静态服务器后访问：

```bash
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/nonlinear/第06次课_混沌与分岔/第06次课_补充_μ与Rn计算方法.html
```
